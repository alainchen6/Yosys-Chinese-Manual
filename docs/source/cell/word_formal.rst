形式化验证单元
--------------


.. role:: yoscrypt(code)
   :language: yoscrypt

.. note::

   有些前端可能不支持通用的 `$check` 单元，在这种情况下，调用
   :yoscrypt:`chformal -lower` 会把每个 `$check` 单元转换为其等价形式。更多信息请
   参阅 `chformal`。

.. todo:: 描述形式化单元

   `$check`、`$assert`、`$assume`、`$live`、`$fair`、`$cover`、`$equiv`、
   `$initstate`、`$anyconst`、`$anyseq`、`$anyinit`、`$allconst` 和 `$allseq`。

   还有 `$ff` 和 `$_FF_` 单元。
