存储器
~~~~~~


存储器要么用 ``RTLIL::Memory`` 对象以及 `$memrd_v2`、`$memwr_v2` 和 `$meminit_v2`
单元来表示，要么单独用 `$mem_v2` 单元来表示。

在第一种方案中，``RTLIL::Memory`` 对象保存存储器的通用元数据（位宽、以字为单位
的深度等），并且为每个端口创建一个 `$memrd_v2` （读端口）或 `$memwr_v2` （写
端口）单元。为读、写端口保留独立单元的优点是，它们可以通过资源共享
pass（处理流程）进行合并。在某些情况下，这会大幅减少存储器单元所需的端口数量。
在这种方案中，存储器初始化数据由 `$meminit_v2` 单元表示，这样可以把初始化地址
和数据的常量折叠推迟到前端完成之后。

`$memrd_v2` 单元有一个时钟输入 ``CLK``、一个使能输入 ``EN``、一个地址输入
``ADDR``、一个数据输出 ``DATA``、一个异步复位输入 ``ARST``，以及一个同步复位
输入 ``SRST``。它们还有以下参数：

``MEMID``
   与此读端口关联的 ``RTLIL::Memory`` 对象的名称。

``ABITS``
   地址位数（``ADDR`` 输入端口的宽度）。

``WIDTH``
   数据位数（``DATA`` 输出端口的宽度）。注意，它可以是底层存储器宽度的 2 的幂
   倍数 —— 这样的端口称为宽端口，一次访问一组对齐的单元。在这种情况下，
   ``ADDR`` 对应的低位必须接 0。

``CLK_ENABLE``
   当该参数非零时使用时钟。否则该读端口是异步的，不使用 ``CLK`` 输入。

``CLK_POLARITY``
   如果该参数的值为 ``1'b1``，时钟在上升沿有效；如果为 ``1'b0``，则在下降沿
   有效。

``TRANSPARENCY_MASK``
   该参数是一个写端口位掩码，列出此读端口对其透明的写端口。该参数的各比特以写
   端口的 ``PORTID`` 参数为索引。透明性只能在共享同一时钟域的同步端口之间启用。
   当对某一对端口启用透明性时，在同一周期内对同一地址的读和写将返回新值。否则
   返回旧值。

``COLLISION_X_MASK``
   该参数是一个位掩码，表示此端口与哪些写端口之间具有未定义的冲突行为。该参数
   的各比特以写端口的 ``PORTID`` 参数为索引。这种行为只能在共享同一时钟域的
   同步端口之间启用。当对某一对端口启用未定义冲突时，在同一周期内对同一地址的
   读和写将返回未定义值（全 X 值）。对于给定的端口对，该选项与透明性选项互斥。

``ARST_VALUE``
   只要 ``ARST`` 输入有效，数据输出就会被复位为该值。仅用于同步端口。

``SRST_VALUE``
   只要 ``SRST`` 输入被同步置位，数据输出就会被复位为该值。仅用于同步端口。

``INIT_VALUE``
   同步端口数据输出的初始值。

``CE_OVER_SRST``
   如果该参数非零，则仅当 ``EN`` 为真时才识别 ``SRST`` 输入。否则无论 ``EN``
   如何都会识别 ``SRST``。

`$memwr_v2` 单元有一个时钟输入 ``CLK``、一个使能输入 ``EN`` （每个数据位对应
一位使能）、一个地址输入 ``ADDR`` 和一个数据输入 ``DATA``。它们还有以下参数：

``MEMID``
   与此写端口关联的 ``RTLIL::Memory`` 对象的名称。

``ABITS``
   地址位数（``ADDR`` 输入端口的宽度）。

``WIDTH``
   数据位数（``DATA`` 输出端口的宽度）。与 `$memrd_v2` 单元一样，宽度可以是存
   储器宽度的任意 2 的幂倍数，并对地址有相应的限制。

``CLK_ENABLE``
   当该参数非零时使用时钟。否则该写端口是异步的，不使用 ``CLK`` 输入。

``CLK_POLARITY``
   如果该参数的值为 ``1'b1``，时钟在上升沿有效；如果为 ``1'b0``，则在下降沿
   有效。

``PORTID``
   此写端口的标识符，用于索引写端口位掩码参数。

``PRIORITY_MASK``
   该参数是一个写端口位掩码，表示在写入同一地址时此写端口优先于哪些写端口。
   该参数的各比特以另一个写端口的 ``PORTID`` 参数为索引。写端口只能优先于端口 ID
   更低的写端口。当两个端口写入同一地址且彼此都没有优先级时，结果未定义。优先
   级只能在同一时钟域的两个同步端口之间设置。

`$meminit_v2` 单元有一个地址输入 ``ADDR``、一个数据输入 ``DATA`` （``DATA``
端口宽度等于 ``WIDTH`` 参数乘以 ``WORDS`` 参数），以及一个位使能掩码输入 ``EN``
（宽度等于 ``WIDTH`` 参数）。三个输入都必须解析为常量，综合才能成功。

``MEMID``
   与此初始化单元关联的 ``RTLIL::Memory`` 对象的名称。

``ABITS``
   地址位数（``ADDR`` 输入端口的宽度）。

``WIDTH``
   每个存储器位置的数据位数。

``WORDS``
   此单元初始化的连续存储器位置的数量。

``PRIORITY``
   该参数整数值较大的单元在初始化冲突中胜出。

HDL 前端使用 ``RTLIL::Memory`` 对象以及异步的 `$memrd_v2` 和 `$memwr_v2` 单元
来建模存储器。`memory` pass（即它的各个子 pass）会把 `$dff` 单元迁移到
`$memrd_v2` 和 `$memwr_v2` 单元中，使其变为同步的，然后把它们转换为单个
`$mem_v2` 单元，并（可选地）把这种单元类型映射为针对各个字的 `$dff` 单元，以
及针对读、写接口的基于多路复用器的地址译码器。当最后一步被禁用或无法进行时，
设计中会留下一个 `$mem_v2` 单元。

`$mem_v2` 单元提供以下参数：

``MEMID``
   变成此 `$mem_v2` 单元的原始 ``RTLIL::Memory`` 对象的名称。

``SIZE``
   存储器中的字数。

``ABITS``
   地址位数。

``WIDTH``
   每个字的数据位数。

``INIT``
   存储器的初始内容。

``RD_PORTS``
   此存储器单元上读端口的数量。

``RD_WIDE_CONTINUATION``
   该参数宽度为 ``RD_PORTS`` 位，包含“宽连续”读端口的位掩码。这类端口用于在
   合并后的单元中表示宽端口多出来的数据位，其所有控制信号必须与前一个端口完全
   一致，只有地址例外——地址的低位必须编码正确的子单元地址。

``RD_CLK_ENABLE``
   该参数宽度为 ``RD_PORTS`` 位，为每个读端口包含一位时钟使能位。

``RD_CLK_POLARITY``
   该参数宽度为 ``RD_PORTS`` 位，为每个读端口包含一位时钟极性位。

``RD_TRANSPARENCY_MASK``
   该参数宽度为 ``RD_PORTS*WR_PORTS`` 位，包含原始 `$memrd_v2` 单元所有
   ``TRANSPARENCY_MASK`` 值的拼接。

``RD_COLLISION_X_MASK``
   该参数宽度为 ``RD_PORTS*WR_PORTS`` 位，包含原始 `$memrd_v2` 单元所有
   ``COLLISION_X_MASK`` 值的拼接。

``RD_CE_OVER_SRST``
   该参数宽度为 ``RD_PORTS`` 位，决定每个读端口的同步复位与使能的相对优先级。

``RD_INIT_VALUE``
   该参数宽度为 ``RD_PORTS*WIDTH`` 位，包含每个同步读端口的初始值。

``RD_ARST_VALUE``
   该参数宽度为 ``RD_PORTS*WIDTH`` 位，包含每个同步读端口的异步复位值。

``RD_SRST_VALUE``
   该参数宽度为 ``RD_PORTS*WIDTH`` 位，包含每个同步读端口的同步复位值。

``WR_PORTS``
   此存储器单元上写端口的数量。

``WR_WIDE_CONTINUATION``
   该参数宽度为 ``WR_PORTS`` 位，包含“宽连续”写端口的位掩码。

``WR_CLK_ENABLE``
   该参数宽度为 ``WR_PORTS`` 位，为每个写端口包含一位时钟使能位。

``WR_CLK_POLARITY``
   该参数宽度为 ``WR_PORTS`` 位，为每个写端口包含一位时钟极性位。

``WR_PRIORITY_MASK``
   该参数宽度为 ``WR_PORTS*WR_PORTS`` 位，包含原始 `$memwr_v2` 单元所有
   ``PRIORITY_MASK`` 值的拼接。

`$mem_v2` 单元有以下端口：

``RD_CLK``
   该输入宽度为 ``RD_PORTS`` 位，包含所有读端口的时钟信号。

``RD_EN``
   该输入宽度为 ``RD_PORTS`` 位，包含所有读端口的使能信号。

``RD_ADDR``
   该输入宽度为 ``RD_PORTS*ABITS`` 位，包含所有读端口的地址信号。

``RD_DATA``
   该输出宽度为 ``RD_PORTS*WIDTH`` 位，包含所有读端口的数据信号。

``RD_ARST``
   该输入宽度为 ``RD_PORTS`` 位，包含所有读端口的异步复位信号。

``RD_SRST``
   该输入宽度为 ``RD_PORTS`` 位，包含所有读端口的同步复位信号。

``WR_CLK``
   该输入宽度为 ``WR_PORTS`` 位，包含所有写端口的时钟信号。

``WR_EN``
   该输入宽度为 ``WR_PORTS*WIDTH`` 位，包含所有写端口的使能信号。

``WR_ADDR``
   该输入宽度为 ``WR_PORTS*ABITS`` 位，包含所有写端口的地址信号。

``WR_DATA``
   该输入宽度为 ``WR_PORTS*WIDTH`` 位，包含所有写端口的数据信号。

`memory_collect` pass 可以把属于同一存储器的离散 `$memrd_v2`、`$memwr_v2` 和
`$meminit_v2` 单元转换为单个 `$mem_v2` 单元，而 `memory_unpack` pass 执行相反的
操作。`memory_dff` pass 可以把由寄存器驱动或驱动寄存器的异步存储器端口合并为同
步存储器端口。`memory_bram` pass 可用于识别哪些 `$mem_v2` 单元可以用 FPGA 上
的块 RAM 资源实现。`memory_map` pass 可用于把 `$mem_v2` 单元实现为基本逻辑：
整字宽的 DFF 和地址译码器。
