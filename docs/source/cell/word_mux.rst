多路复用器
----------


多路复用器由 Verilog HDL 前端为 ``?:`` 表达式生成。多路复用器也会由 proc pass（处理
流程）生成，用于把 RTLIL::Process 对象中的决策树映射为逻辑。

最简单的多路复用器单元类型是 `$mux`。该类型的单元有一个 ``WITDH`` 参数、数据输入
``A`` 和 ``B`` 以及数据输出 ``Y``，宽度均为所指定的宽度。该单元还有一个单比特控制输入
``S``。如果 ``S`` 为 0，输入 ``A`` 的值被送到输出；如果为 1，``B`` 输入的值被送到
输出。因此 `$mux` 单元实现函数 :verilog:`Y = S ? B : A`。

`$pmux` 单元用于在 one-hot 选择信号的控制下在许多输入之间进行多路复用。该类型的
单元有一个 ``WIDTH`` 和一个 ``S_WIDTH`` 参数，以及输入 ``A``、``B`` 和 ``S`` 和一个
输出 ``Y``。``S`` 输入的宽度为 ``S_WIDTH`` 位。``A`` 输入和输出都是 ``WIDTH`` 位宽，
``B`` 输入为 ``WIDTH*S_WIDTH`` 位宽。当 ``S`` 的所有位都为零时，``A`` 输入的值被送
到输出。如果 ``S`` 的第 :math:`n` 位被置位，则 ``B`` 输入中第 :math:`n` 个
``WIDTH`` 位宽的切片被送到输出。当 ``S`` 中多于一位被置位时，输出未定义。该类型的
单元用于建模“并行分支”（parallel cases，通过使用 ``parallel_case`` 属性、``unique``
或 ``unique0`` SystemVerilog 关键字定义，或由优化过程检测到）。

`$tribuf` 单元用于实现三态逻辑。该类型的单元有一个 ``WIDTH`` 参数、输入 ``A`` 和
``EN`` 以及一个输出 ``Y``。``A`` 输入和 ``Y`` 输出为 ``WIDTH`` 位宽，``EN`` 输入为
一比特宽。当 ``EN`` 为 0 时，输出未被驱动。当 ``EN`` 为 1 时，``A`` 输入的值被送到
``Y`` 输出。因此 `$tribuf` 单元实现函数 :verilog:`Y = EN ? A : 'bz`。

带有级联 if-then-else 和 case 语句的行为级代码通常会产生多路复用器单元树。许多 pass
（处理流程），从各种优化到有限状态机（FSM）提取，都严重依赖这些多路复用器树来理解
信号之间的依赖关系。因此优化不应破坏这些多路复用器树（例如，把计算得到的信号与常量
零之间的多路复用器替换为 `$and` 门）。
