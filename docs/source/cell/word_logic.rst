任意逻辑函数
------------


`$lut` 单元类型实现单输出 LUT（查找表）。它通过 ``\LUT`` 参数实现任意逻辑函数，把
输入端口 ``\A`` 映射为输出端口 ``\Y`` 的取值。用伪代码表示为：``Y = \LUT[A]``。
``\A`` 的宽度由参数 ``\WIDTH`` 设定，``\Y`` 的宽度为 1。每个单比特输出的逻辑函数都有
唯一的 `$lut` 表示。

`$sop` 单元类型实现积之和（sum-of-products）表达式，也称为析取范式（DNF）。它实现
任意逻辑函数。其结构模仿可编程逻辑阵列（PLA）。输出端口 ``\Y`` 是由参数 ``\TABLE``
定义的输入端口 ``\A`` 各位的乘积之和。``\A`` 的宽度为 ``\WIDTH`` 位。和式中的乘积
个数由参数 ``\DEPTH`` 设定，每个乘积对每个输入位有两位——分别表示该输入位的未取反
版本和取反版本是否出现在该乘积中。因此 ``\TABLE`` 参数包含
``2 * \WIDTH * \DEPTH`` 位。

例如：

设 ``\WIDTH`` 为 3。我们希望表示 ``\Y =~\A[0] + \A[1]~\A[2]``。共有 2 个乘积要求和，
因此 ``\DEPTH`` 应为 2。

.. code-block::

    ~A[2]-----+
     A[2]----+|
    ~A[1]---+||
     A[1]--+|||
    ~A[0]-+||||
     A[0]+|||||
         |||||| product formula
         010000 ~\A[0]
         001001 \A[1]~\A[2]

于是 ``\TABLE`` 的值将变为 ``010000001001``。

任何单比特输出的逻辑函数都可以用 ``$sop`` 表示，但在 ``\TABLE`` 取值中可以有不同的
化简程度或排列顺序的求和项。
