调试单元
--------


`$print` 单元用于记录信号的值，类似于 Verilog 中 ``$display`` 和 ``$write`` 系列
任务（并且可以转换为它们）。它有以下参数：

``FORMAT``
   内部格式字符串。语法见下文。

``ARGS_WIDTH``
   ``ARGS`` 端口上信号的宽度（以位为单位）。

``TRG_ENABLE``
   若为真，则在 ``TRG`` 中定义的特定信号上触发；若为假，则每当 ``ARGS`` 或
   ``EN`` 变化且 ``EN`` 为 1 时触发。

如果 ``TRG_ENABLE`` 为真，则以下参数同样适用：

``TRG_WIDTH``
   ``TRG`` 端口中的位数。

``TRG_POLARITY``
   对于 ``TRG`` 中的每一位，若该信号为上升沿触发则为 1，若为下降沿触发则为 0。

``PRIORITY``
   当多个 `$print` 或 `$check` 单元在同一触发条件下触发时，它们按优先级降序
   执行。

端口：

``TRG``
   控制此 `$print` 单元何时触发的信号。

   如果该端口的宽度为零且 ``TRG_ENABLE`` 为真，则该单元仅在初始求值（时间零）
   期间触发。

``EN``
   整个单元的使能信号。

``ARGS``
   要显示的值，按格式字符串的顺序排列。

格式字符串语法
~~~~~~~~~~~~~~


格式字符串语法类似于 Python 的 f-string。普通文本会原样传递，直到遇到以 ``{``
开始的格式说明符。

格式说明符具有以下语法。除非另有说明，所有项都是必需的：

``{``
   表示格式说明符的开始。

size
   信号大小（以位为单位）；该说明符从 ``ARGS`` 端口消耗这么多位。

``:``
   将大小与其余项分隔开。

justify
   ``>`` 表示右对齐，``<`` 表示左对齐。

padding
   ``0`` 表示零填充，空格表示空格填充。

width\ *?*
   （可选）要填充到的字符宽度。

base
   * ``b`` 表示 2 进制整数（二进制）
   * ``o`` 表示 8 进制整数（八进制）
   * ``d`` 表示 10 进制整数（十进制）
   * ``h`` 表示 16 进制整数（十六进制）
   * ``c`` 表示 ASCII 字符/字符串
   * ``t`` 和 ``r`` 表示仿真时间（分别对应 :verilog:`$time` 和
     :verilog:`$realtime`）

对于整数，后面可以跟这一项：

``+``\ *?*
   （可选，仅十进制）为非负数添加前导加号。这有助于在表格化输出中与负数保持
   对称。

signedness
   ``u`` 表示无符号，``s`` 表示有符号。该区别仅在渲染十进制时生效。

ASCII 字符/字符串没有特殊选项，但信号大小必须能被 8 整除。

对于仿真时间，信号大小必须为零。

最后：

``}``
   表示格式说明符的结束。

一些格式说明符示例：

+ ``{8:>02hu}`` - 8 位无符号整数，以十六进制渲染，右对齐，零填充到 2 个字符宽。
+ ``{32:< 15d+s}`` - 32 位有符号整数，以十进制渲染，左对齐，空格填充到 15 个
  字符宽，正值前缀为 ``+``。
+ ``{16:< 10hu}`` - 16 位无符号整数，以十六进制渲染，左对齐，空格填充到 10 个
  字符宽。
+ ``{0:>010t}`` - 仿真时间，右对齐，零填充到 10 个字符宽。

要在格式字符串中包含字面量 ``{`` 和 ``}`` 字符，请分别使用 ``{{`` 和 ``}}``。

如果格式字符串从 ``ARGS`` 消耗的位数多于或少于端口宽度，就会报错。

无论指定的宽度是多少，值都不会被截断。

注意，根据所使用的后端不同，对允许的选项组合可能还有进一步的限制。

例如，Verilog 没有允许对字符串（即多于 1 个 ASCII 字符）进行零填充的格式说明
符，但允许对单个字符进行零填充。

因此，RTLIL 格式说明符 ``{8:>02c}`` 会转换为 ``%02c``，而 ``{16:>02c}`` 无法用
Verilog 表示，会导出失败。这种情况下必须使用 ``{16:> 02c}``，它会转换为
``%2s``。
