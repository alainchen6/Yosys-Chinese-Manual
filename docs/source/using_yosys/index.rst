使用 Yosys（进阶）
==================

许多其他有用的事情。因此本节分为两部分：
:doc:`/using_yosys/synthesis/index` 在
:doc:`/getting_started/example_synth` 的基础上展开，进一步详述综合中使用的主要
命令；:doc:`/using_yosys/more_scripting/index` 介绍 Yosys 与设计交互以进行更深入
调查的各种方式。
