控制流与数据流
==============


.. todo:: 少些学术腔

典型综合工具的数据流和控制流与典型编译器的数据流和控制流非常相似：不同的子系统
按预先确定的顺序被调用，每个子系统读取上一个子系统生成的数据，并为下一个子系统
生成数据（参见 :numref:`图 %s <fig:approach_flow>`）。

.. figure:: /_images/internals/approach_flow.svg
	:class: width-helper invert-helper
	:name: fig:approach_flow

	综合工具的一般数据流和控制流

第一个被调用的子系统通常称为前端。它不处理其他子系统生成的数据，而是读取用户的
输入——对于 HDL 综合工具而言，就是行为级 HDL 代码。

那些读取前一个子系统的数据、并为下一个子系统生成数据（通常采用相同或相似的格式）
的子系统称为 pass（处理流程）。

最后执行的子系统把上一个 pass 生成的数据转换为合适的输出格式，并写入磁盘文件。
这个子系统通常称为后端。

在 Yosys 中，所有前端、pass 和后端都直接以综合脚本中的命令形式提供。因此，用户
只需在综合脚本中按正确顺序调用 pass，就能轻松创建自定义综合流程。
